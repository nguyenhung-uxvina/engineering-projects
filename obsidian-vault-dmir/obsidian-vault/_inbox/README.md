# 📥 Inbox

> **Purpose**: Quick capture zone for unprocessed notes
> **Rule**: Process items within 24-48 hours

---

## How to Use

1. **Capture quickly** - Don't worry about organization, just get it down
2. **Process regularly** - Daily or every other day
3. **Move to proper location** - After processing, move to domains/skills/templates

---

## Processing Checklist

When processing an inbox item:

- [ ] Is this a decision? → Move to `domains/[project]/decisions/`
- [ ] Is this research? → Move to `domains/[project]/research/`
- [ ] Is this a reusable process? → Move to `skills/`
- [ ] Is this a template? → Move to `templates/`
- [ ] Is this project-specific? → Move to `domains/[project]/`
- [ ] Is this trash? → Delete it
