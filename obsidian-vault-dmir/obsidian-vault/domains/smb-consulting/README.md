## 📋 Engagement Framework

### Phase 1: Discovery (Day 1)

**Objectives**:
- Map value stream end-to-end
- Identify constraint candidates
- Understand business goals

**Deliverables**:
- Value stream map
- Preliminary constraint hypothesis
- Data collection plan

**Tools**:
- [[skills/toc-analysis]] - Constraint analysis
- [[templates/value-stream-map]] - VSM template

### Phase 2: Measurement (Days 2-5)

**Objectives**:
- Confirm constraint with data
- Measure current throughput
- Identify exploitation opportunities

**Key Metrics**:
- Throughput (units/day, revenue/day)
- WIP at each step
- Utilization at constraint
- Quality issues at constraint

### Phase 3: Quick Wins (Week 2)

**Objectives**:
- Implement exploitation actions
- Measure improvement
- Build credibility

**Focus Areas**:
- Reduce downtime at constraint
- Ensure constraint never starves
- Clear output blockages

### Phase 4: Systematic Change (Weeks 3-12)

**Objectives**:
- Subordinate non-constraints
- Implement DBR scheduling
- Train team

**Components**:
- Drum: Constraint schedule
- Buffer: Time buffer before constraint
- Rope: Release logic

## 💰 Pricing Model

### Value-Based Pricing

```
Price = Base Fee + (Throughput Gain × Value Factor)

Where:
- Base Fee covers diagnostic work
- Throughput Gain measured in units or revenue
- Value Factor = 10-20% of annual gain value
```

### Example Calculation

```
Client: Electronics assembly
Current throughput: 100 units/day
After engagement: 130 units/day (+30%)
Annual gain: 30 units × 250 days × $50 margin = $375,000

Pricing:
- Base Fee: $5,000
- Value Share: $375,000 × 15% = $56,250
- Negotiated: $25,000 - $40,000

ROI for client: 10-15x
```
