## 2. UNIVERSAL JOB MAP (PRIMARY EXECUTOR)

```
VN-CAM-T1 UNIVERSAL JOB MAP (8 Steps)
═══════════════════════════════════════════════════════════════════════════

STEP 1: DEFINE (Define training objectives)
├─ Define training objectives for session
├─ Set success criteria for shooters (qualifying scores)
├─ Define session parameters (duration, exercises, drills)
├─ Establish performance baseline for each trainee
└─ Identify specific technique areas to focus on

STEP 2: LOCATE (Identify and gather resources)
├─ Identify shooter positions on range
├─ Define safety zones (no-go areas, firing lanes)
├─ Verify equipment status (cameras, LOMAH, targets)
├─ Confirm network connectivity
└─ Locate reference materials (SOPs, drill cards)

STEP 3: PREPARE (Set up for execution)
├─ Position cameras for optimal coverage
├─ Calibrate system (lens focus, tracking zones)
├─ Load AI models (pose detection, flinch classification)
├─ Synchronize with LOMAH (shot detection system)
├─ Configure shooter profiles (name, unit, baseline)
└─ Test audio/visual feedback systems

STEP 4: CONFIRM (Verify readiness)
├─ Verify safety zones are clear of personnel
├─ Confirm system is ready to record
├─ Ensure shooter understands feedback mechanism
├─ Verify recording is active (green indicator)
├─ Confirm LOMAH sync is operational
└─ Validate audio alert volume is appropriate

STEP 5: EXECUTE (Perform core job)
├─ Track shooter pose (17-point skeleton)
├─ Monitor safety zones continuously
├─ Detect flinch/anticipation errors in real-time
├─ Correlate shots with LOMAH data
├─ Provide immediate audio/visual feedback
├─ Score shooting technique continuously
└─ Capture video clips of critical moments

STEP 6: MONITOR (Observe and assess)
├─ Analyze pose stability in real-time
├─ Track performance trends during session
├─ Detect safety violations immediately
├─ Monitor system health (temperature, connectivity)
├─ Compare performance to baseline
├─ Identify technique degradation patterns
└─ Monitor fatigue indicators

STEP 7: MODIFY (Make adjustments)
├─ Adjust AI feedback sensitivity (strictness)
├─ Update safety zone boundaries
├─ Re-calibrate tracking if drift detected
├─ Modify drill parameters based on performance
├─ Switch between training modes (coached vs. self-paced)
└─ Adjust audio feedback type (verbal vs. tone)

STEP 8: CONCLUDE (Complete and document)
├─ Generate After Action Review (AAR)
├─ Export performance data to LMS
├─ Create highlight clips of key errors
├─ Reset system for next shooter
├─ Document session summary and incidents
├─ Archive raw video for later analysis
└─ Generate improvement recommendations
```
