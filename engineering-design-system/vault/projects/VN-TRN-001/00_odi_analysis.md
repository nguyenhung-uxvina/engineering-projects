# ODI Analysis - VN-TRN-001: Vietnamese LOMAH System

## Job Executor

**Primary:** Range Officer / Range NCO (Si quan/Ha si quan Truong ban)

## Core Functional Job

> "Assess marksmanship accuracy of shooters on a live-fire range using electronic scoring"

## Universal Job Map

| Step | Stage | What Range Officer Does |
|------|-------|------------------------|
| 1. DEFINE | Define exercise parameters | Select course of fire, lanes, targets, scoring criteria, pass/fail |
| 2. LOCATE | Gather resources | Assign lanes, verify ammo compatibility, check range safety |
| 3. PREPARE | System setup | Power on, run BIT, verify comms, mount sensors, confirm zones |
| 4. CONFIRM | System verification | Fire test shots (or calibration-free verify), confirm display |
| 5. EXECUTE | Operate during exercise | Monitor hits, manage target exposure, track shots per lane |
| 6. MONITOR | System health | Watch errors, verify lanes reporting, check power, detect faults |
| 7. MODIFY | Adjust during exercise | Change scenarios, re-assign lanes, handle malfunctions |
| 8. CONCLUDE | Report and teardown | Generate reports, export AAR, compute stats, store, power down |
