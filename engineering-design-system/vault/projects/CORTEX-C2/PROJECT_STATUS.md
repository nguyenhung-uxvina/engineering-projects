## Product Concept

### Definition
> **CORTEX C2 "THẦN TOÁN"** is an AI-based central command & control platform that unifies training management, combat operations, and base defense across a networked ecosystem of 13+ sensor/weapon products. Using 6 specialized AI engines, it transforms raw multi-sensor data into actionable intelligence — learning continuously from operational data to improve decision quality over time.

### Innovation Strategy
- **Primary (Y1-2):** Differentiation — Segments A (Decision Dominance) + C (Training Analytics)
- **Long-term (Y3+):** Dominant — Better AI + cheaper platform economics across ALL segments
- **Disruptive (Segment D):** Counter-UAS C2 at 1/5 price of DroneShield

### Key System Dynamics
- **R1: Data Flywheel** — More customers → more data → better AI → higher value → more customers
- **R2: Network Effect** — More bases using CORTEX → cross-base intelligence → enterprise sales
- **R3: AI Learning Loop** — Cross-sensor data (acoustic + visual + weapons) → unique competitive moat
- **B1: Complexity Brake** — More editions → more features → more bugs (mitigate: 80% shared code)
- **B2: Talent Constraint** — Growth limited by engineering capacity (mitigate: AI self-service)
