## 3. MODULE 2: SAFETY & HANDLING (60 min)
## MÔ-ĐUN 2: AN TOÀN & XỬ LÝ

### 3.1 Safety Rules / Quy Tắc An Toàn

```
⚠️ CRITICAL SAFETY RULES / QUY TẮC AN TOÀN QUAN TRỌNG
═══════════════════════════════════════════════════════════════════════════

RULE 1: ALWAYS TREAT AS LOADED
QUY TẮC 1: LUÔN COI NHƯ ĐÃ NẠP ĐẠN
───────────────────────────────────────────────────────────────────────────
• Never point at anything you don't intend to engage
• Không bao giờ chĩa vào thứ bạn không định tác chiến

RULE 2: KEEP SAFETY ON UNTIL READY TO FIRE
QUY TẮC 2: GIỮ KHÓA AN TOÀN ĐẾN KHI SẴN SÀNG BẮN
───────────────────────────────────────────────────────────────────────────
• Safety switch in SAFE position at all times except firing
• Khóa an toàn ở vị trí AN TOÀN mọi lúc trừ khi bắn

RULE 3: BE SURE OF TARGET AND BEYOND
QUY TẮC 3: CHẮC CHẮN VỀ MỤC TIÊU VÀ PHÍA SAU
───────────────────────────────────────────────────────────────────────────
• Identify target positively before engaging
• Xác định chắc chắn mục tiêu trước khi tác chiến

RULE 4: KEEP FINGER OFF TRIGGER UNTIL READY
QUY TẮC 4: GIỮ NGÓN TAY KHỎI CÒ ĐẾN KHI SẴN SÀNG
───────────────────────────────────────────────────────────────────────────
• Index finger outside trigger guard until aimed at target
• Ngón trỏ ngoài vòng cò cho đến khi ngắm vào mục tiêu

═══════════════════════════════════════════════════════════════════════════
```

```

═══════════════════════════════════════════════════════════════════════════

STEP 1: ACQUIRE TARGET / XÁC ĐỊNH MỤC TIÊU

```
TROUBLESHOOTING GUIDE / HƯỚNG DẪN XỬ LÝ SỰ CỐ

───────────────────────────────────────────────────────────────────────────
Causes / Nguyên nhân:
• Dead battery / Pin hết
• Battery not installed correctly / Pin lắp sai
• Power switch fault / Lỗi công tắc nguồn

Solution / Giải pháp:
1. Check battery charge / Kiểm tra mức sạc pin
2. Reinstall battery / Lắp lại pin
3. Try spare battery / Thử pin dự phòng
4. If still fails → Unit maintenance / Nếu vẫn lỗi → Bảo dưỡng cấp đơn vị

PROBLEM: Won't fire / KHÔNG BẮN ĐƯỢC
───────────────────────────────────────────────────────────────────────────
Causes / Nguyên nhân:
• Safety still engaged / Khóa an toàn vẫn bật
• ARM switch OFF / Công tắc ARM tắt
• No ammunition loaded / Chưa nạp đạn
• Low battery / Pin yếu

Solution / Giải pháp:
1. Verify: Safety → FIRE, ARM → ON
   Xác nhận: An toàn → BẮN, ARM → BẬT
2. Verify ammunition loaded / Xác nhận đã nạp đạn
3. Check battery level ≥10% / Kiểm tra pin ≥10%
4. Cycle ARM switch OFF-ON / Tắt-bật công tắc ARM
5. If still fails → Clear and inspect / Nếu vẫn lỗi → Tháo và kiểm tra

PROBLEM: Optics not working / QUANG HỌC KHÔNG HOẠT ĐỘNG

Causes / Nguyên nhân:
• Optics battery dead / Pin quang học hết
• Optics not connected / Quang học không kết nối
• Optics damaged / Quang học hư hỏng

Solution / Giải pháp:
1. Replace optics battery / Thay pin quang học
2. Check connection / Kiểm tra kết nối
3. Replace optics module / Thay mô-đun quang học

PROBLEM: Misfire / BẮN HỤT
───────────────────────────────────────────────────────────────────────────
IMMEDIATE ACTION / HÀNH ĐỘNG NGAY:
1. Keep muzzle pointed safe / Giữ nòng hướng an toàn
2. Wait 30 seconds / Chờ 30 giây
3. Safety → SAFE, ARM → OFF
   An toàn → AN TOÀN, ARM → TẮT
4. Carefully open breech / Cẩn thận mở khóa nòng
5. Remove round, inspect / Lấy đạn ra, kiểm tra
6. If round defective → Dispose safely / Nếu đạn lỗi → Hủy an toàn

### 6.2 Error Codes / Mã Lỗi

| Code | Meaning / Ý nghĩa | Action / Hành động |
|------|-------------------|-------------------|
| E01 | Low battery / Pin yếu | Replace battery / Thay pin |
| E02 | Sensor fault / Lỗi cảm biến | Unit maintenance / Bảo dưỡng |
| E03 | Overtemp / Quá nhiệt | Let cool, then retry / Để nguội, thử lại |
| E04 | Comms error / Lỗi truyền thông | Reset system / Khởi động lại |
| E05 | System fault / Lỗi hệ thống | Depot maintenance / Bảo dưỡng cấp kho |

### 6.3 When to Seek Help / Khi Nào Cần Trợ Giúp

- Problem persists after troubleshooting / Vấn đề còn sau khi xử lý
- Physical damage observed / Có hư hỏng vật lý
- Error code E05 displayed / Hiện mã lỗi E05
- Safety concern / Lo ngại về an toàn
